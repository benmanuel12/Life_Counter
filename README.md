# Magic the Gathering Life Counter

Basic webpage that allows for the tracking of life totals during a 2 or 4 player game of Magic the Gathering

## Built with
HTML, CSS, JS, Node.js, Express

## Features
- Defaults to 20 life per player
- Can set starting life to any number
- Can support 4 players with Commander mode in settings
- Can alter individual players life values with the color coded + and - buttons
- Can recolor each tracker to one of the 5 Magic colors
- Can reset values to starting life with reset button
- Changing starting life does not reset life to starting life, in case you need to continue the current game

## Running it
- npm install
- npm start
- Go to localhost:3000
